CHAPTER V

THE BLUEPRINT

Not a product you wait for — a repository you clone. The schematic is source code and the compiler checks it. Gerbers, firmware, config app: all of it, in the open.

INVENTORY · openmicrokbd MIT LICENSE
  • openmicrokbd/ The whole thing. Clone it and go.
  • ├─ hw/v1/src/ The schematic — written in CoHDL, typed and compiler-checked. The PCB is a program.
  • ├─ hw/v1/out/ What the compiler emits: netlist, BOM, footprints, layout constraints.
  • ├─ hw/v1/pcb/ The routed board, ready to open in KiCad.
  • ├─ hw/v1/fab/ Gerbers, BOM, pick-and-place — upload straight to a fab.
  • ├─ fw/ Rust firmware on embassy: key matrix, twin RGB chains, USB HID, one-click updates.
  • ├─ app/ The config app — Rust + GPUI. Remap live, save to the board, flash firmware.
  • └─ README.md Every step, every part, every price.

A blueprint anyone can replicate — compile it, solder it, flash it, fork it. Under $40 in parts, and no permission required.

★ Get the Blueprint on GitHub ▼ Download the App

The config app ships as a notarized macOS disk image — Apple Silicon and Intel — with every release, next to the firmware binaries. Windows and Linux build from source out of app/.
